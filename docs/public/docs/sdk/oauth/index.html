    Oauth Module#

    package oauth // import "github.com/JLugagne/egauth/oauth"

Package oauth implements the OAuth2 authorization-code flow (with PKCE) as
stateless, composable HTTP handlers. It ships ready-made Google, GitHub and
Discord providers and a generic New constructor for any other compliant
provider. Following egauth's philosophy the package is HTTP-decentralized (it
exposes handler builders, not a router) and depends only on the standard library
plus the egauth identity/tokens packages — no third-party OAuth SDK.
