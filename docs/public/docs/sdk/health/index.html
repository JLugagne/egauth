    Health Module#

    package health // import "github.com/JLugagne/egauth/health"

Package health defines the optional health-check seam implemented by egauth's
pgx-backed stores, so readiness/liveness probes can be written against any store
without depending on a specific backend or holding a separate handle to the
underlying connection pool.
