    Mfa Module#

    package mfa // import "github.com/JLugagne/egauth/mfa"

Package mfa implements multi-factor authentication: time-based one-time
passwords (TOTP, RFC 6238 / RFC 4226) for authenticator apps, and single-use
recovery codes. It follows egauth's conventions — a stateful Store interface
(memory + pgx implementations, a shared contract suite), a stateless-ish Service
for orchestration, and à-la-carte HTTP handlers — and depends only on the
standard library plus google/uuid.

SMS / phone factors are intentionally NOT supported (authenticator apps only).
